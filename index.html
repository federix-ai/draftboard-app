What it does

One window for every agent you run.

Draftboard doesn't replace your agents: it runs the CLIs you already use, signed in with your own accounts, and lays them out where you can see who is working and who is waiting for you.

Real terminals on a canvas

Each node is a full terminal. Zoom, pan, arrange. A sidebar shows who needs you, who is working and who is idle; ⌘J jumps to the next one waiting.

Linked agents talk

Drag a line between two nodes. Inside the terminal, agents use orch send to message a colleague; messages wait in a queue until the receiver is free.

Teams in one click

Launch a ready-made team, already linked, and give the leader the task. Or build your own and save it.

A worktree per agent

In a git repo every agent gets its own orch/<name> branch, so nobody steps on anyone. The Git panel shows the graph, diffs, commit, push and branch switching.

Floors for experiments

Copy a whole workspace and its repos instantly with APFS clones. Try an idea on a floor, then bring the branches back, or throw it away.

Point at the bug

Web and iOS Simulator nodes next to the agents. Capture the screen, circle what's wrong, add a note, and send it to the agent linked to it.

Open a folder

Pick a project or clone one from Git. Draftboard finds the repository and its branch.

Launch a team

Press ⇧⌘T, pick a team and write the task. The leader splits it and hands it out.

Watch, approve, steer

Follow the work on the canvas and step in only when an agent needs you.

# inside any terminal on the board
$ orch list                      # linked colleagues and their status
$ orch send reviewer "Ready for review on orch/coder"
$ orch tasks                     # the project's phases and open tasks
$ orch task done 3fa9c1

Install

Two minutes, once.

Get it running

  1. Download Draftboard.dmg, open it and drag Draftboard into Applications.
  2. Open Draftboard. macOS says it can't verify the developer: click Done.
  3. Go to System Settings › Privacy & Security and, near the bottom, click Open Anyway next to Draftboard.

This version is not notarized by Apple yet, so macOS asks you to allow it once.

Requirements

  • macOS 14 or later on Apple Silicon.
  • At least one agent CLI installed and signed in in your terminal: claude, codex, gemini or opencode.
  • git (Command Line Tools) for worktrees and the Git panel.
  • No account and nothing to configure: agents run with your existing logins.

Stop juggling terminal tabs.

Put your agents on one board, link them up and let them work together.
